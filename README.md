# Girls in Tech – Website Prototype

## Overview

A mock website designed and developed for UBCO Girls in Tech club as part of a club interview process. The project explores how a website could represent the club and communicate its mission.

## Technologies Used

- HTML
- CSS

## Project Objectives

- Create a visually appealing and user-friendly website.
- Design a layout that reflects the club's identity and purpose.
- Apply foundational front-end web development concepts.
- Organize and present information in a clear and accessible manner.

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.

## Project Status

This project is an independent website prototype and is not the club's official website.
